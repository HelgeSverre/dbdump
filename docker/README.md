# Docker test infrastructure

Reproducible database servers for testing dbdump, plus a programmatic smoke
test. Everything here is meant to be re-runnable so these checks can be repeated
as the tool changes.

## Layout

| File | Purpose |
|------|---------|
| `docker-compose.yml` | Plaintext MySQL 5.7 / 8.0 / 8.4 and MariaDB 10.11 (ports 3307–3310). Used by the integration tests and the profile smoke test. |
| `docker-compose.tls.yml` | TLS-enforcing MySQL 8.0 (3320) and MariaDB 10.11 (3321) that reject plaintext connections. |
| `certs/gen-certs.sh` | Generates a self-signed CA plus server and client certs into `certs/` (git-ignored). |
| `smoke-test.sh` | End-to-end smoke test: profiles across MySQL versions, and all TLS modes. |

## Smoke test

```bash
./docker/smoke-test.sh            # profiles + TLS (default)
./docker/smoke-test.sh profiles   # only the version/profile matrix
./docker/smoke-test.sh tls        # only the TLS matrix
KEEP=1 ./docker/smoke-test.sh tls # leave containers running afterwards

just smoke            # same, via just
just smoke tls
```

It builds `dbdump`, brings the relevant containers up (waiting for health),
seeds a small table, and asserts:

- **Profiles:** `config add` + `--profile` connect, list, and dump against MySQL
  5.7 / 8.0 / 8.4 and MariaDB.
- **TLS:** for each TLS-enforcing server, `require`, `verify-ca`,
  `verify-identity`, and mutual TLS all connect and dump, and a plaintext
  connection is correctly rejected.

Containers are torn down on exit unless `KEEP=1`.

## Manual use

```bash
# Plaintext stack
docker compose -f docker/docker-compose.yml up -d
docker compose -f docker/docker-compose.yml down -v

# TLS stack (generate certs first)
./docker/certs/gen-certs.sh
docker compose -f docker/docker-compose.tls.yml up -d
```

The certificates are self-signed and for local testing only; they are
regenerated by `gen-certs.sh` and never committed.
